AI Software Management

Running software development where AI agents do the engineering — governed by shared guidelines and automated checks, so the work stays fast and trustworthy. That is Missing Bulb's specialty. Around it, we do software, management, and AI consulting.

Not a pitch — a working practice

We don't advise on AI-assisted development from the sidelines. We run our own projects this way, every day.

Claudinite — the system

Our open-source corpus of working guidelines, skills, and automated conformance checks for AI coding agents. It decides how an agent names things, structures commits, ties work to issues, and what a change must pass before it lands. Every rule is public — you can read exactly how we keep agent-written software honest.

Dogfooded daily

Missing Bulb's own repositories — this website among them — are built and maintained by AI agents working under Claudinite's rules, with automated checks gating every merge.

What we bring to you

The same practice, applied to your team: where agents fit in your development lifecycle, the guardrails that keep their output reviewable, and the process changes that make the speed real.

How an engagement runs

Small and hands-on

You work directly with the people doing the work. No layers, no handoffs, no slide decks standing in for software.

Working software in weeks

Engagements are scoped to deliver something running early — a working system you can react to, not a long discovery phase.

Scoped, not open-ended

We agree on the outcome and the boundaries up front. When the scope is done, the engagement is done.

What we do

Software consulting

Design, build, and ship. We write working software — web apps, browser extensions, and the tooling around them — and everything we make is public, so you can read the code before you talk to us.

Management consulting

How software teams plan, decide, and deliver. We help you shape the process around the code: what to build, in what order, and how to know it's working.

AI consulting

Practical AI in real products and real workflows — from putting a model behind a feature to putting AI agents to work inside your development process.

AI Software Management consulting

Our specialty: managing software development done with AI. We don't just advise on it — we run our own projects this way, and we built Claudinite, our open system of shared working guidelines and automated checks that keeps coding agents productive and honest.
